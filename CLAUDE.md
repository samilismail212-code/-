## استخدام المهارات / Skills

- استخدم دائماً مهارة `find-skills` (`anthropic-skills:find-skills`) عندما يسأل المستخدم عن كيفية فعل شيء، أو يطلب قدرة جديدة، أو يبحث عن مهارة. ابحث أولاً عن مهارة مناسبة واقترحها قبل البدء بالعمل.
- Always use the `find-skills` skill (`anthropic-skills:find-skills`) whenever the user asks how to do something, requests a new capability, or looks for a skill. Search for a fitting skill and suggest it before starting the work.
